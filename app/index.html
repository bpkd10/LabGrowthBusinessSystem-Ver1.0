AI Business Analyst

ถามข้อมูลธุรกิจของคุณด้วยภาษาปกติ

AI สำหรับวิเคราะห์เฉพาะข้อมูลในระบบเท่านั้น

หน้านี้เป็นส่วนเสริมที่ต้องใช้ API key ของคุณเอง · ถ้ายังไม่มี key ได้เลย ที่นั่นคำนวณตัวเลขชุดเดียวกันจากข้อมูลในระบบโดยตรง และดาวน์โหลดเป็นรายงาน Excel ได้

1. ตั้งค่า API key ของคุณ

ถ้าบัญชีของคุณไม่มีสิทธิ์ใช้โมเดลนี้ ระบบจะแจ้งให้ทราบ ให้คัดลอกชื่อโมเดลที่บัญชีคุณเข้าถึงได้จากหน้า Models ของ OpenAI มาใส่แทน

วาง key แล้วถามได้ทันที ไม่ต้องกดบันทึก — ปุ่มบันทึกมีไว้สำหรับคนที่ไม่อยากพิมพ์ใหม่ทุกครั้งเท่านั้น

ยังไม่ได้ตั้งค่า key

key ของคุณเดินทางไปไหนบ้างตรวจสอบเองได้
  1. อยู่ในเบราว์เซอร์ของคุณ ถ้าไม่กดบันทึก key จะอยู่แค่ในช่องกรอกของแท็บนี้ ปิดแท็บแล้วหายทันที ไม่ถูกเขียนลงเครื่องเลย
  2. ส่งผ่านเซิร์ฟเวอร์ของระบบไปยัง OpenAI เพราะ OpenAI ไม่ยอมให้เบราว์เซอร์เรียกตรง ๆ ตัวส่งต่อไม่เก็บ ไม่บันทึก log และไม่มี key ของตัวเอง
  3. ไม่มีฐานข้อมูลใดเก็บ key ไว้ ระบบนี้ไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์เลย ทั้งข้อมูลธุรกิจและ key

ตรวจเอง: กด F12 → แท็บ Network → ส่งคำถาม จะเห็นคำขอออกไปที่ /api/ai-relay ของเว็บนี้เพียงรายการเดียว ไม่มีคำขอไปที่อื่น

ข้อจำกัดตามจริง: เมื่อ key วิ่งผ่านเซิร์ฟเวอร์ คุณต้องเชื่อใจว่าเจ้าของระบบไม่ได้แอบบันทึกไว้ ถ้ายังไม่สบายใจ ให้สร้าง Project API key แยกเฉพาะแอปนี้ ตั้ง spend limit ไว้ต่ำ ๆ แล้วเพิกถอนทิ้งหลังใช้เสร็จ วิธีนี้ทำให้ความเสี่ยงสูงสุดของคุณเท่ากับวงเงินที่ตั้งไว้เท่านั้น

key ที่เก็บไว้ในเบราว์เซอร์อ่านได้โดย JavaScript ทุกตัวที่รันบนหน้านี้ รวมถึงส่วนขยายของเบราว์เซอร์ แนะนำให้สร้าง Project API key แยกสำหรับแอปนี้ และตั้ง spend limit ไว้ใน OpenAI dashboard ถ้าใช้เครื่องร่วมกับคนอื่น อย่าติ๊ก “จำ key ไว้ในเครื่องนี้” และกดลบ key ก่อนออกจากเครื่อง

2. เลือกมิติที่ต้องการวิเคราะห์

ข้อมูลที่ AI อ่าน Business Profileลูกค้าและ Leadดีลและ PipelinePackageงานติดตาม
ข้อมูลที่ส่งไม่มีรูปโปรไฟล์และเบอร์โทรลูกค้า · คำขอถูกส่งต่อผ่าน server ของระบบนี้ไปยัง OpenAI ด้วย API key ของคุณเอง ทั้ง key และข้อมูลธุรกิจผ่าน server แค่ระหว่างส่งต่อ ไม่ถูกบันทึกหรือเก็บไว้ · key ถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น และ JavaScript ที่รันบนหน้านี้อ่านได้ ค่าใช้จ่ายการเรียก AI เป็นของบัญชีคุณเอง
